# market 使用说明(给自己人 · 朋友版)

> 部署者注意:发送前把 `<接入地址>` 替换为完整令牌 URL,并提醒对方按私密信息保存。

## 进入

浏览器打开(建议收藏):

```
<接入地址>
```

首次打开会自动跳转进入工作台;之后直接访问同一 IP 端口即可(首次已自动记住凭证,30 天内免令牌)。

## 能做什么

- **对话**:像普通 AI 助手一样提问;涉及行情数据时它会自己调用工具查(规则、筛选、运行状态),不用你提供截图
- **右侧「资产」标签**:点开资产区
  - 「筛选与规则」:填门槛条件点「立即筛选」;满意就「存为规则」持续监控
  - 「运行」:看调度状态、手动模拟跑一轮、看最近事件
  - 「0AMV」:看市场活跃度指标
  - 「设置」:数据源 Key、通知方式(先问我再改)

## 遇到问题

1. **打不开/404**:地址复制完整了吗?令牌部分一个字符都不能少;还不行就等 2 分钟重试(服务可能在更新)
2. **筛选报「API Key 未配置」**:在「设置」页签填入 FMP Key,或直接在对话里说"把 fmpApiKey 设为 xxx"
3. **筛选很慢**:全量美股模式本来就要逐批拉数据,几百支约 1-3 分钟;急用就改手动代码模式(AAPL,MSFT 这种)
4. **AI 回答异常**:新开一个会话再试;持续异常把"对话里看到的报错原文"发给我

## 两条纪律

- 「规则」列表是共用的:动开关、删规则前先在对话里问我
- 「设置」里的通知邮箱、调度间隔会影响整体,改之前先说一声
