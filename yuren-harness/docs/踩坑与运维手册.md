# Yuren Harness · 踩坑与运维手册

> 从盈宝选矿助手项目一个月实战提炼(完整版在其仓库 docs/开发交接记录.md,29 条)。
> 这里保留对本底座仍有效的大部分,按主题归类。

## dsh 补丁与插件

1. **补丁语法**:新增行 `- insert:`;覆盖已有行用裸 `- id:` 条目;禁用 `disabled: true`;
   `config` 为整值替换(不做深度合并)。insert 加同 id 行 → `duplicate loader entry id`。
2. **覆盖行的 `name` 是防呆校验**,不是替换手段(name 不一致整行跳过)。换插件 = disabled 禁默认行 + insert 新行。
3. **本地插件双解析陷阱**:加载器按 ESM import 解析(Windows 盘符路径报 ERR_UNSUPPORTED_ESM_URL_SCHEME,
   必须 `file:///` URL),client-modules 扫描器用 require.resolve(只认盘符路径)——互斥。
   所以品牌插件的浏览器半不走 `dsh.client` 自动发现,由 host 半改写 `__DSH_BOOT__` 启动图注入
   + 精确路由(`/branding/client.js`)提供(harness/brand 已实现,别动这个结构)。
4. **界面品牌三顽固点**:①插槽不注册走 FishLogo 回退;②document.title 被渲染器反复重写,
   要 defineProperty 拦截;③locale 字典 register 重复注册抛异常,只能改字典后 publish(品牌插件已处理,
   含"命名空间可能晚于插件激活"的轮询重试;for...of 迭代普通对象会静默炸,必须 Object.entries)。

## 运行时与部署

5. **`--expose-internals`**:ELECTRON_RUN_AS_NODE 跑 dsh 时缺它,后端先监听(页面正常)再崩——
   界面全在但所有请求 Failed to fetch。纯 Node 不受影响。
6. **数据目录别放系统保护文件夹**:Windows Defender 勒索软件防护默认保护 Documents,
   未签名程序写入被系统性拦截(EPERM)。放用户主目录(web 形态 `~/.yuren-harness`,桌面 `%USERPROFILE%\<产品>`)。
7. **workspace.json 必须带 unit 头**(`{unit:{name:"workspace",version:2}}`),dsh-storage-json
   硬校验;缺了启动即崩且界面看不出。写它一律走"种子函数"(serve.js / desktop main.js 已内置,幂等自愈)。
8. **技能/文件同步要内容指纹跳过**:每次启动全量 rm+cp 会随机撞 OneDrive/杀毒/索引器加锁(EPERM),
   且失败必须 fail-soft(告警不阻断)。
9. **正常退出进程零残留**:退出钩子里 taskkill /T(树杀)。任务管理器强杀主进程可能留下后端+MCP 子进程
   (占端口,下次启动自动换端口,重启自然清)。
10. **API 信任域**:前端从别的域名访问 API 必须加 `--trusted-host`(serve.js 的 YUREN_TRUSTED_HOSTS);
    nginx 同域反代则无需。WebSocket(/api/events.*)反代要带 Upgrade 头 + 关 buffering(SSE 实时性)。
11. **一次部署 = 一个共享工作区**(DSH_HOME 全局共享,无每用户账号)。多小组隔离 = 多进程多 DSH_HOME。

## 打包(桌面分支)

12. **electron-builder 按依赖清单剪枝**:dsh 大量运行时包未在包清单声明(原工作区平铺依赖),
    按闭包打包缺 46 个包;在 dist 内启动会"楼上借依赖"假性正常,拷出去立刻 ERR_MODULE_NOT_FOUND。
    解法:完整 node_modules 经 **afterPack 钩子**(hooks.js)原样复制。
13. **extraResources 对含 node_modules 的目录不可靠**(交给依赖收集器:整个丢掉或剪空),必须走 afterPack。
14. **fastmcp 锁 3.4.7**:3.5+ 拆掉 server 支持需 fastmcp-slim[server];自检判据要认 `gofastmcp.com`
    且排除 ImportError(错误文本里也含"FastMCP",会假阳性)。PEP723 内联依赖声明同样锁版本。
15. **NSIS 静默安装 `/S /D=<路径>` 经 Git Bash 会被 MSYS 吃掉斜杠**导致卡交互——用 PowerShell Start-Process 或 bat。
16. **SmartScreen**:"仍要运行"仅安装时一次;彻底消除需代码签名证书。

## 环境与工具链(开发机)

17. **Git Bash 三坑**:MSYS 吃 `/E`、`/S` 这类开关(MSYS_NO_PATHCONV=1 或 PowerShell/bat);
    `powershell -Command` 里的 `$_` 被吞(写 .ps1 再 -File);中文 bat 别从 Git Bash 跑(GBK)。
18. **写入通道坑**:Bash heredoc 传 python 的 `\b`/`\n` 会被吃一层(用脚本文件/Edit 工具);
    Edit 偶发直引号变弯引号(JS 语法炸)——写完立刻语法检查。
19. **timeout 杀不掉 GUI exe**:残留进程占产物文件导致重打包 EPERM;测完 `taskkill /IM <exe> /T /F`。
20. **验证自包含性必须把产物挪出开发目录树**,否则 Node 向上解析借到开发 node_modules,假性正常。

## 模型接入(通用)

21. **各厂商多体系 Key↔端点必须匹配**:订阅/按量/国际版互不通用,混用一律 401 Invalid Authentication。
    例:Kimi 订阅走 api.kimi.com/coding(模型 k3),按量走 api.moonshot.ai(kimi-k3);
    智谱编程套餐 OpenAI 协议走专用 /api/coding/paas/v4;ChatGPT Plus/Claude Pro 会员不是 API Key。
    排查先绕过应用直接 curl 对应端点。
22. **端点/模型版本会漂移**:PRESETS 里的快照超 30 天未核对要重新检索确认。

## dsh 升级流程

改 `web/package.json`(与 desktop 的 package.json)里的 `@deepseek-ai/dsh` 版本 → npm install →
跑通"环境/数值/守则/记忆/边界"验收(尤其 Failed-to-fetch 类隐性崩溃,必须真调一次 /api RPC)→
重新打桌面包。切忌 `latest`:上游发版随时可能引入不兼容。
