# Yuren Harness · 移植指南(用本底座做领域产品)

> 参考实作:盈宝选矿助手(选矿试验方案 + 经济评价)。照下面顺序做,15–30 分钟起壳,
> 剩下的时间全部花在领域内容上。

## 1. 起壳

```bash
cp -r yuren-harness 你的产品目录 && cd 你的产品目录
rm -rf .git && git init -b main    # 从模板出发永远自带新仓库
```

## 2. 改品牌(所有"可见之处")

| 文件 | 改什么 |
|---|---|
| `harness/brand/lib/index.js` | `APP_TITLE` |
| `harness/brand/lib/client.js` | 侧栏名 `TailingsBrandName`?→ 产品名;hero 标语(中英);欢迎弹窗标题/正文/示例问法(中英);description/onboarding 文案可保留(本就通用) |
| `harness/brand/manifest.webmanifest` | name/short_name |
| `harness/brand/favicon.svg` | 配色/图形(四条几何在 `<rect>` 里改 fill 即可) |
| `desktop/electron-app/main.js` | `APP_TITLE`(窗口标题/数据目录名 `%USERPROFILE%\yuren-harness` 建议一并改产品名) |
| `desktop/electron-app/loader.html` | 标题与副标 |
| `desktop/electron-app/package.json` | productName/nsis artifactName/shortcutName |
| 全局 | `grep -r "Yuren" .` 收尾确认 |

预设(九家厂商×双协议)与获取 Key 链接、报错人话化**不用改**——那是通用资产。
模型/端点有变时只改 `client.js` 的 `PRESETS`(注意各厂商订阅/按量/国际版端点互不通用,混用 401)。

## 3. 改智能体行为(提示词层)

- `AGENTS.md`:整体改写(守则模板里有骨架;铁律部分建议保留);
- `harness/cordis.template.yml` 与 `cordis.desktop.template.yml` 末尾的 `persona:` 改成领域专家人设;
- 两个模板保持同步修改(同一套人设)。

## 4. 加领域工具与技能

- MCP:复制 `harness/mcp-servers/example_server.py` 改写(经验库 keys 关键词匹配模式);
  在 `harness/cordis.template.yml` 取消 `mcp-mydomain` 注释并填绝对路径(web 形态,python3+uv 方式),
  桌面形态在 `cordis.desktop.template.yml` 加行并 `make_vendor.py --with-python`;
- 技能:按 `harness/skills/example-skill/SKILL.md` 结构写,自动同步免配置。

## 5. 密钥预置(可选,交付更省心)

管理员机配好 Key → `python3 tools/export_provision.py` →
web 形态放服务器 `~/.yuren-harness/provision/profile.yaml`;
桌面形态放目标机 `%USERPROFILE%\yuren-harness\provision\`。首启自动导入,用户不见配置弹窗。

## 6. 交付

- Web 主形态:按 `web/README.md` 部署(pm2/systemd/nginx);
- 桌面分支:Windows 开发机双击 `构建桌面版.bat`,产物即安装器。

## 7. 验收建议

从盈宝项目照抄思路:环境组(MCP 在线/技能识别/模型连通)、确定性数值组(锚点值用
工具实算锁定)、守则铁律组(缺数据追问/安全前置/假设标注/交付物落盘)、记忆组、边界组。
