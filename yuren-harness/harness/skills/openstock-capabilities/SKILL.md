# 能力总览

## 工具全景（OpenStock MCP，数据源 FMP）

| 类别 | 工具 | 要点 |
|---|---|---|
| 个股快照 | `get_quote` | 实时价/涨跌幅、市值、成交额、换手、52 周高低、近期新高标志、公司摘要（20h 缓存） |
| 业绩与估值 | `get_financials` | 三大报表序列 + 增速/利润率/FCF/负债率 + PE/PS/PB/EV/ROE 序列 + 分析师预期（年度）+ 分红史（48h 缓存） |
| 走势回溯 | `get_price_history` | 日线区间（默认 6 个月、上限 2 年）+ 涨跌幅/高低/SMA20/60 摘要 |
| 财报日历 | `get_earnings_calendar` | 未来 1-30 天，含 EPS/营收预期，只列美股（按代码后缀过滤） |
| 同业对比 | `get_peers` | 同行业可比清单，含现价/市值，可再逐个深挖 |
| 行情筛选 | `run_screener` | 价格/市值/涨跌幅/换手/近期新高条件；手动 symbol 列表或全市场（maxScan 默认 500） |
| 财报筛选 | `run_financial_screener` | 营收增速/毛利率/EBITDA/现金流/负债门槛；走 FMP Premium 字段，慢，maxScan 建议 30-100 |
| 规则管理 | `list_rules` / `add_rule` / `save_rules` | 查看规则；单条追加；全量替换前必须先展示差异 |
| 一轮检查 | `run_rules_once` | 默认 dry_run 只评估不通知；真实发送必须用户确认后显式 dry_run=false |
| 规则回测 | `backtest_rule` | 规则名或临时条件 + 1-10 个代码，回看 1-5 年：触发次数 + 触发后 1/5/20 日胜率/均值 |
| 大盘活跃度 | `compute_amv` / `get_amv_history` | 0AMV（标普/纳指/全量）当前值与历史 |
| 运行现场 | `get_status` / `get_recent_events` | 调度器状态、最近一轮结果、事件流 |
| 配置 | `get_config` / `update_config` | 读取永远脱敏；写入用补丁合并 |
| 其它 | `web_search`、记忆工具、工作区文件读写 | 公开资料须注来源与日期；超 30 天的数据提示时效 |

## 数据口径速记

- 行情快照缓存 20 小时、财务统计缓存 48 小时：报"实时价"时顺带报数据时间。
- 全市场候选池已剔除 ETF、共同基金、非活跃标的（保留公司股票与 ADR）；池子按市值降序取前 maxScan，实际能扫到的最小市值约 22-23 亿美元。
- 行情新鲜度闸门：数据日早于"最近交易日 −7 天"的标的自动跳过（防退市僵尸代码假信号）。
- 缺 FMP Key 时工具直接报错：转告用户到面板「设置」填写，不要反复重试。
- FMP 全市场首轮又慢又易限流：先用小样本（手动列表或 maxScan≤100）验证链路。

## 做不到的事（用户问到就如实说）

- 看不到用户本地文件；需要时请用户在对话里上传附件。
- 不能下单交易，不是券商；不给买卖建议，只给数据、筛选、规则与回测。
- 没有盘中 tick 级数据；行情粒度是日线加快照。
- 不能修改服务器代码；功能问题走仓库 → CI 部署流程。
- API 密钥永远脱敏，任何人都拿不到明文。
- 跨会话记忆已持久化到磁盘（重启不丢）：值得记的口径、偏好、研究结论主动存档；用户要求遗忘时删除对应条目。
